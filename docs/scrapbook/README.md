# Loom Scrapbook

External sources, adjacent projects, incidents, standards, and other "loot chests" worth preserving before they deserve architecture.

Each source or investigation gets its own Markdown file so that notes can remain comprehensive, attributable, and independently addressable without turning `docs/scrapbook.md` into an ever-growing monolith.

Entries are exploratory unless they explicitly say otherwise. They may contain:

- observations about the source;
- concepts worth stealing or adapting;
- overlap with Loom's existing design;
- conflicts or mismatches;
- things Loom already does differently or more strongly;
- open questions and possible experiments;
- attribution and source links.

Keep the distinction between **observed**, **inferred**, **proposed**, and **adopted** ideas explicit.

The older `docs/scrapbook.md` remains historical material. New source-specific investigations should normally live in this directory.
